# Plantilla Tienda de Ropa

Prototipo base para el emprendimiento de creación de páginas web.

## Estructura
- index.html: estructura de la página
- css/styles.css: estilos y responsive
- js/script.js: productos, buscador y carrito demo
- assets/images/: recursos visuales

## Nota
Las fotos del catálogo usan imágenes externas de Unsplash para el prototipo. En un proyecto real se pueden reemplazar por fotografías y recursos del cliente.
