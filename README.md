# ColombiaStyle V2 — Plantilla de catálogo

## Abrir
1. Descomprime el ZIP.
2. Abre `index.html`.
3. No requiere instalación de Node.js ni servidor.

## Nuevas secciones
- Marcas internacionales seleccionables: Nike, adidas, PUMA, Levi's, ZARA, H&M y Skechers.
- Sección de producción/marcas nacionales: Totto, Vélez, Koaj, Leonisa, Arturo Calle, Gef y Studio F.
- Cada marca funciona como filtro del catálogo.
- Botón "Ver todo el catálogo".
- Sección de punto físico.
- Botón "Cómo llegar" que abre Google Maps.
- Buscador por producto, marca o categoría.
- Carrito de demostración.

## Importante
Las marcas se muestran como categorías de catálogo. La plantilla no afirma que exista afiliación, distribución oficial o autorización de esas marcas.

## Personalización
En `js/script.js` puedes modificar productos, marcas, precios y categorías.
En `index.html` cambia nombre, dirección, redes y textos.
En `css/styles.css` cambia colores y diseño.
La dirección del botón "Cómo llegar" está en el enlace de `index.html`; reemplázala por la dirección real del negocio.
